# 📘 SQL Cheat Sheet

A quick-reference guide covering the most essential SQL commands and concepts. Perfect for interviews, study, or daily development use.

---

### 🔹 Basic Commands
- `SELECT`, `FROM`, `WHERE`
- `ORDER BY`, `GROUP BY`, `HAVING`
- Logical operators (`AND`, `OR`, `NOT`)
- Comparison operators (`=`, `>`, `<`, `LIKE`, `IN`, `BETWEEN`)

### 🔹 Data Manipulation Language (DML)
- `INSERT INTO`
- `UPDATE`
- `DELETE`

### 🔹 Data Definition Language (DDL)
- `CREATE TABLE`
- `ALTER TABLE`
- `DROP TABLE`
- Common data types

### 🔹 Joins
- `INNER JOIN`
- `LEFT JOIN`
- `RIGHT JOIN`
- `FULL OUTER JOIN`
- `CROSS JOIN`

### 🔹 Aggregate Functions
- `COUNT()`
- `SUM()`
- `AVG()`
- `MAX()`
- `MIN()`

### 🔹 Subqueries
- Subqueries in `WHERE`
- Subqueries in `SELECT`
- Correlated subqueries

### 🔹 Views & Procedures
- `CREATE VIEW`
- `CREATE PROCEDURE`
- `CREATE FUNCTION`
- Triggers

### 🔹 Indexes
- `CREATE INDEX`
- `UNIQUE INDEX`
- When and why to use indexes

---


## 🧠 Purpose

This project aims to provide a clean, concise, and practical SQL reference for data engineers, analysts, developers, and students who need a quick reminder of SQL syntax and patterns.
